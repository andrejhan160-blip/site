# Sadullaev Marketing — сайт

Главная страница с офферами и три лендинга: недвижимость, миграция,
автобизнес. Плюс страница политики конфиденциальности.

Домен: **sadullaev.pro** — уже прописан в `canonical`, `og:url`, `og:image`,
JSON-LD, `sitemap.xml` и `robots.txt`.

Сборки самодостаточные: React, шрифты и изображения зашиты внутрь HTML,
внешних запросов нет — страницы работают даже без интернета.

## Что заливать на хостинг

```
index.html            главная — выбор направления
nedvizhimost/         лендинг «Лиды в недвижимость»
migraciya/            лендинг «Лиды в миграцию»
avtobiznes/           лендинг «Лиды в автобизнес»
politika/             политика конфиденциальности
favicon.svg           иконка вкладки
cover.jpg             картинка для превью ссылок в мессенджерах (1200×630)
robots.txt            разрешение на индексацию + путь к карте сайта
sitemap.xml           карта сайта
set-domain.sh         смена домена, если понадобится (на хостинг не нужен)
```

**Важно:** содержимое папки кладётся в корень `sadullaev.pro`. Ссылки между
страницами абсолютные (`/nedvizhimost/`, `/migraciya/`, `/avtobiznes/`),
поэтому из подпапки вроде `sadullaev.pro/landing/` они работать не будут.

## После заливки

1. **HTTPS.** Включить сертификат в панели хостинга и редирект с `http://`
   на `https://`, а также с `www.sadullaev.pro` на `sadullaev.pro` (или
   наоборот — важно, чтобы вариант совпадал с `canonical`, там указан
   адрес без `www`).
2. **Проверить превью ссылки.** Отправить `https://sadullaev.pro` себе
   в Telegram — должна подтянуться картинка с первым экраном и заголовок.
3. **Подтвердить форму** — см. раздел ниже.
4. **Search Console и Яндекс.Вебмастер.** Добавить сайт, отправить
   `https://sadullaev.pro/sitemap.xml`.

Если домен когда-нибудь поменяется, все адреса переписываются одной командой:

```sh
sh set-domain.sh new-domain.com
```

## Формы заявок

На странице `/avtobiznes/` есть форма («Прогноз по клиентам»). Она отправляет
заявку через сервис **formsubmit.co** на почту `evgeniqstart@gmail.com`,
вместе с UTM-метками, адресом страницы и реферером.

**Formsubmit требует однократной активации:** после первой отправки формы
с боевого домена на почту придёт письмо со ссылкой подтверждения — по ней
нужно перейти. До этого заявки доходить не будут. Проверить стоит сразу
после заливки: отправить тестовую заявку и подтвердить адрес.

На остальных страницах форм нет — кнопки ведут в Telegram и WhatsApp.

## Что добавлено к сборке из дизайн-редактора

Редактор отдаёт страницы с `<title>Bundled Page</title>` и без метаданных.
Дооснащено:

- **SEO:** осмысленные `title` и `description` для каждой страницы, Open Graph
  и Twitter Card, `canonical`, микроразметка Schema.org (ProfessionalService
  с тарифами и географией), `robots`, `theme-color`, `lang="ru"`, `viewport`.
- **Повторная простановка метатегов.** Сборщик заменяет `documentElement`
  целиком и стирает исходный `<head>`, поэтому статических тегов хватает
  только краулерам без JS (Telegram, WhatsApp, Facebook). Небольшой скрипт
  возвращает `title`, метатеги, `canonical` и JSON-LD обратно после рендера —
  для Googlebot и Яндекса, которые исполняют JavaScript.
- **Фолбэк без JS:** скрытый блок с H1, описанием, ссылками на разделы
  и контактами. Показывается, если JavaScript отключён.
- **Правки вёрстки на узких экранах.** Сетки с фиксированной минимальной
  колонкой (`minmax(300px, 1fr)` и шире) больше не растягивают страницу.
  Длинные слова в заголовках («квалифицированных», «конфиденциальности»)
  автоматически уменьшаются до размера, при котором помещаются в колонку.
  Проверено на 320–1920px: горизонтальной прокрутки нет нигде.
- **favicon, cover.jpg, robots.txt, sitemap.xml.**

## Известное ограничение

Страницы весят от 0,6 до 5,9 МБ: React, шрифты и изображения зашиты в каждый
файл — так собирает дизайн-инструмент. Самая тяжёлая — `avtobiznes/`.
Чтобы уменьшить вес, нужна пересборка из исходников: общий бандл React,
отдельные файлы картинок в WebP и один набор шрифтов на весь сайт.
