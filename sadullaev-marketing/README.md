# Sadullaev Marketing — лендинг

Отдельный статический лендинг (тёплые лиды на недвижимость). Никакой сборки —
это готовый `index.html`, который можно открыть или залить на любой хостинг.

## Файлы

- `realestate.html` — лендинг по недвижимости (весь CSS и JS внутри).
- `migration.html` — лендинг по миграции (ВНЖ, визы, иммиграция).
- `index.html` — вход: мгновенный редирект на `realestate.html`.
  Сделан намеренно: в корне репозитория лежит другой `index.html`
  (сайт по кровле), и уникальные имена страниц исключают путаницу
  при заливке на хостинг.
- `favicon.svg` — иконка вкладки.
- `img/` — изображения (пока пусто, см. список ниже).

## Что нужно доделать перед публикацией

1. **Домен.** В `index.html` заменить `SITE_URL` на реальный домен — встречается
   в `canonical`, `og:url`, `og:image` и в блоке JSON-LD (в самом верху файла).
2. **Обложка для соцсетей.** Положить `cover.jpg` (1200×630) в корень папки — она
   используется в `og:image` при отправке ссылки в мессенджеры.
3. **Изображения** — все основные уже на месте; список ниже для справки.

Размеры — ориентир (2× от отображаемого для чёткости на Retina). Пропорции
важнее точных пикселей: блоки обрезаются через `object-fit: cover`.
Пока файлов нет — на их месте просто тёмные блоки, вёрстка не ломается.

**Статистика рекламного кабинета** (справа от оффера) — это `stat-1.png` и
`stat-2.png`. Кладутся в `img/`, показываются в рамке с тенью на тёмном фоне.
Порядок сверху вниз = номер файла. Светлый скрин из Facebook на тёмном фоне
смотрится нормально за счёт рамки; если хочется — можно обрезать по краям.

**Скрины сделок**: `review-2.jpg` («Мы на сделке») стоит у сделки $300K,
`review-3.png` («Мы это сделали») — у сделки $560K. Для сделки $650K ждём
файл `deal-3.png`.

**Логотипы клиентов** («Мне доверяют») — отдельные файлы logo-*.{jpg,png,svg,webp}
в плитках: белые подложки для тёмных лого, фирменный тёмно-синий у IBG и Colife.
Секция отзывов удалена по решению клиента; скрины переписок живут в «Сделках».

## Что уже улучшено относительно исходника

- **SEO:** canonical, Twitter-теги, `og:image` с размерами, микроразметка
  Schema.org (ProfessionalService + оффера), `robots`, `theme-color`.
- **Скорость:** preload и `fetchpriority` для hero, `loading="lazy"` +
  `decoding="async"` для остальных картинок, заданы размеры (меньше «прыжков»
  вёрстки при загрузке — CLS).
- **Мобильная адаптация:** полноценное бургер-меню вместо скрытых ссылок,
  плавающая кнопка «Написать», аккуратные тап-зоны.
- **Дизайн:** плавное появление секций при скролле (с учётом
  `prefers-reduced-motion`), hover-эффекты на карточках/тарифах, кликабельные
  цены-CTA в тарифах, «премиальная» подсветка эксклюзивных пунктов вместо
  тревожно-красной, галочки в списках тарифов.
- **Доступность:** skip-ссылка, aria-атрибуты меню, `aria-live` у счётчика
  кейсов, безопасный рендер карточек (экранирование).
- **Надёжность:** битые ссылки на кейсы (`#`) больше не ведут в никуда —
  карточка показывается как «Скоро».
