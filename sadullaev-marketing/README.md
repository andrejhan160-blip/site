# Sadullaev Marketing — лендинги

Два статических лендинга в новом (светлом) дизайне. Сборки самодостаточные:
React и все изображения встроены внутрь HTML, внешних запросов нет —
файлы работают даже без интернета.

## Файлы для хостинга

- `realestate.html` — лендинг «Лиды в недвижимость».
- `migration.html` — лендинг «Лиды в миграцию» (ВНЖ, визы, иммиграция).
- `index.html` — точка входа: мгновенный редирект на `realestate.html`.
- `favicon.svg` — иконка вкладки.

Для публикации достаточно этих четырёх файлов: положить в корень хостинга.
Папка `img/` нужна только как архив исходных изображений — на хостинг её
загружать не требуется, страницы её не используют.

## Почему уникальные имена

В корне репозитория лежит другой `index.html` (сайт по кровле). Страница
недвижимости названа `realestate.html`, поэтому перекрёстные ссылки между
лендингами не могут случайно попасть на чужой сайт.

## Что нужно доделать перед публикацией

1. **Домен.** Заменить `SITE_URL` на реальный адрес в `realestate.html` и
   `migration.html` — встречается в `canonical`, `og:url`, `og:image`
   и в блоке JSON-LD (в начале файла).
2. **Обложка для соцсетей.** Положить `cover.jpg` (1200×630) рядом с
   HTML-файлами — используется в `og:image` при отправке ссылки в мессенджеры.

## Что добавлено к дизайнерской сборке

Исходные бандлы приходили без метаданных (`<title>Bundled Page</title>`).
Дооснащено:

- **SEO:** осмысленные `title` и `description`, Open Graph и Twitter Card,
  `canonical`, микроразметка Schema.org (ProfessionalService + офферы тарифов),
  `robots`, `theme-color`, `lang="ru"`.
- **Фолбэк без JS:** страницы рендерятся скриптом, поэтому добавлен скрытый
  блок с H1, оффером и контактами. Он показывается, если JavaScript отключён,
  и помогает ботам мессенджеров и поисковиков.
- **Перекрёстные ссылки** между лендингами приведены к `realestate.html`
  и `migration.html`.
- **favicon** под новую светлую тему.

## Известные ограничения

Страницы весят 2,5 и 1,5 МБ: React и изображения зашиты в каждый файл
(так собирает дизайн-инструмент). Чтобы уменьшить вес, нужна пересборка из
исходников с отдельными файлами картинок и общим бандлом.
